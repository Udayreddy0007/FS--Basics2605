Structure of the HTML :
in html everything is treated as tags <>(angular brackets)
open angular bracket / open tag <>
closed angular bracket / close tag </>
-- in html we have multiple tags
-- HTML element - which gives a complete structure <> content</>
-- HTML Attribute - a tag html element which as some information which is written inside the opening tag
--     ex: <a href="">

<!DOCTYPE HTML> -- giving instruction to a page / using HTML standards
<html lang="en"> --- root element / entry to a house -- lang is a attribute en - language code/attribute value en- english
<head> ------------ it stores the info about our web page which is not displayed on the main page
  <meta charset ="UTF-8"> --- it setup encoding  (Unicode transition format) it interpret the text into the byte code(0,1)
  <meta name ="viewport" content ="width=device-width" initial-scale=1.0> -- name ="viewport"-- the area of the page  content =-"width=device-width" -- auto set the width of the page
                                                                              initial-scale=1.0 by default add the zoom in and zoom out
  <title>Document</title> -- it will add the name to the browser tab
</head> -- close 
<body>  --- the content which is displayed on the main
</body>
</html> --- root ended here / exit from the house
