  -----> Rules to decalre a variable / variableName 
   
        1. A vaiable name can contains letter
          
          ex : name  , stdName 

        2 . A variable  name consists of number as well as letter but not starts with number
         
           ex : 1stdname . std1name , stdName1

        3. A variable name cannot contains spaces 
           
           ex :  std Name , stdN_me , std!name 

        4. A variable name can consists of _ , $ 
          
          ex : stdname_ , std$Name 

        5. A variable name can starts with _ as well $ 
           
           ex : 
              _stdname , $stdname
        
        6. A predefined names and special symbols are not considered as variable name 
            except ( _ and $) 

            ex : 
              
              if , count , else if , function, for , while

        7. JS is a case sensitive language  there is different btw Uppercase and Lower case 
          
           ex :   name , Name 
      

        8 . For  the naming convention of variable in Js follows camelCase 
         
           camelCase - stdName  --- JS use this method
           snakecase  - std_Name
           pascalcase - StdName
           capitalcase - STDNAME

   -----> Conditional statements :  
     
       A block of code / A statement  is executed when the  condition is true we call those one as 
        
        conditional statements 


   ----> In js we have 6 types of conditional statements they are 
    
      1 . If conditional statement 
      2 . If else conditional statement 
      3 . Nested if 
      4 .  Else if  
      5 . Nested else if 
      6 . Switch 


  ----> If condition statement  :  When the condition is true then only the  statement is executed  

         --- if block is also called as true block  
           {
              // block
           }

     Syntax : 
               define a variable 
                if(condition){

                      // true statement 
                }

   ----> if else Condition : If the condition is true a true block statement is executed , But if the condition 
                             is false the default block statement is executed 


            -- else is treated as default block 


            syntax : 
              
                     if(condition){
                        // true statement 
                     }
                     else{
                        //default statement
                     }
                               
   ----> Nested if conditional statement : 
         
         where we can write multiple true blocks 

         Syntax : 
            
             if(cond1){
               // true statement 1
             }
             if(cond2){

               // true statement 2
             }
             if(cond3){

               //true statement 3
             }


-----> else if conditional statement : We   defining the two block if true conditions and false conditions are 
                    matching only the block stop execution at true 

         Syntax : 
             
             if(true condition){

               // true statement 
             }
             else if (False condition)
             {
               // False statement 
             }
             else{
               // default statement
             }


---> Nested Else if  conditional statements :  we are writing multiple false block and single true 
 
        Syntax : 
           
           if(true condition){|
                 // true statement
           }
           else if(false condition 1){
            // false statement 1
           }
           else if(false condition 2){
            // false statement 2
           }
           else if(false condition 3){
            // false statement 3
           }
           else{
            // default statement 
           }

 
 ---> Switch Conditional statement : 
    
     here we are writing cases  and passing the expression 


     Syntax : 
        
            Switch(exp){

               case1: 
                    //output statement 
                    break;

               case 2: 
                break ;

                 default : 
                     // default statement ;
            }

   ----> Looping control statements  / Iterative control statements: 
       

       ---  Iterating a statement multiple times  until the stop condition  matchs 
        

    1 . For loop :    Loop execute with initial condition and iterate until the stop condition 
      
            syntax :  
                       
                        for(variable keyword i=0; i<=10; i++){

                          // output statement 
                        }
                     
         

    2. While Loop  : It checks the condition then only statement is executed 

         Syntax :   

                        let i = 0 ; 

                        while(i<=10){

                          console.log();
                          i++;
                        } 


    3 . Do-while loop : At least execute the  statement once and then check the condition 
       
           
           Syntax :   
                    
                     let i = 0;
                       do{

                        // statement  
                          i++;
                       }while(i<=10);

  
  4 . break statement  :  It is used to terminate the loop immediately when a specified condition is satisified
      
      break is a keyword used to terminate the loop
         
         let a = 1 ;
         for(a=1; a<=10; a++){
          console.log(a);
          if(a==5){
            break;
          }
         }


  5. continue statement : The statement is used to skip the conditions 
     
        continue is used to skip the iteration


        let a= 1;
        for(let a=1 ; a<=10; a++){

          console.log(a);
          if(a==5){
            continue;
          }
        }
