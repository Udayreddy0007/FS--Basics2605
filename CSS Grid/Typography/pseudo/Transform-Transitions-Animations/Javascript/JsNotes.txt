-----> Variables in JS : 
   
        A container which stores different types of data  / a name which holds the different value we cal it
         as variable name 
           
        
        ex :  
               name = "Ravi";

               name -- variable  
               variableValue is Ravi -- string Datatypes 

      
  -----> Rules to decalre a variable / variableName 
   
        1. A vaiable name can contains letter
          
          ex : name  , stdName 

        2 . A variable  name consists of number as well as letter but not starts with number
         
           ex : 1stdname . std1name , stdName1

        3. A variable name cannot contains spaces 
           
           ex :  std Name , stdN_me , std!name 

        4. A variable name can consists of _ , $ 
          
          ex : stdname_ , std$Name 

        5. A variable name can starts with _ as well $ 
           
           ex : 
              _stdname , $stdname
        
        6. A predefined names and special symbols are not considered as variable name 
            except ( _ and $) 

            ex : 
              
              if , count , else if , function, for , while

        7. JS is a case sensitive language  there is different btw Uppercase and Lower case 
          
           ex :   name , Name 
      

        8 . For  the naming convention of variable in Js follows camelCase 
         
           camelCase - stdName  --- JS use this method
           snakecase  - std_Name
           pascalcase - StdName
           capitalcase - STDNAME
