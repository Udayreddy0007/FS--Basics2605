 ----> Animations : Changing the styles of an element  to the new styles  we call it as animation 

       @Keyframe AnimationName{
        from{
           
           propertyname:value1;
        }
        to{
          
          propertyname: value2;
        }
       }


       Animation-Name :  name of the animation;
       Animation-duration:sec;   -- How long the should run
       Animation-timing-function:  -- How animation should run
       Animation-delay:              -- How long the animation should stop running before it starts
       Animation-iteration-count:        -- How many times animation should runs
       Aniamtion-direction:              -- In which direction it should run
