

---> Date : box model in css 

 css box model 

 -- margin : the outside portion of html doc
 -- border : the layout / edge of the document
 -- padding : the space inside the border and around the content
 -- content : the element which is displayed on the screen


 ---> Content : 
    
    The content is the innermost part of the box. It contains the actual information displayed inside an element, such as text, images, or other HTML elements.

     We can control the content area's dimensions using the width and height properties.


---> Padding : 
           
           Padding is the space between the content and the border.

          It creates internal spacing inside an element.

          adding can be specified in different ways:

          padding: 10px;                 /* All four sides */
          padding: 10px 20px;            /* Top/bottom, left/right */
          padding: 10px 20px 30px;       /* Top, left/right, bottom */
          padding: 10px 20px 30px 40px; /* Top, right, bottom, left */
          
   -- Note : Remember: the four-value order is top, right, bottom, left (clockwise).


---> Border : 
   
     The border surrounds the content and padding. It creates a visible boundary around an element.

     border: 5px solid black;

---> Margin : 
   
   Margin is the space outside an element's border. It separates an element from neighboring elements

    The margin: 30px; property creates 30 pixels of external spacing on all four sides.

    Margin can also be specified individually:

    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;

---> The order of the box model from outside to inside is:

Margin → Border → Padding → Content

Think of it as layers surrounding the content.

Margin: external spacing

Border: visible boundary

Padding: internal spacing

Content: actual text or other content
