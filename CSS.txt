--> Selectors : Givinga name to  an HTML element and applying the style on the particular 
     elment by using that name

     1. Element Selector : Applying the style by using element name 
             
             Syntax : 
                            Html elementName{
                                CssPropertyName : PropertyValue;
                            }
        
     2. Id Selector : Applying the styles by using Id name 
                       before that we need to give an id to an Element

                       Syntax :  #UniqueIdName {

                                    CssPropertyName : PropertyValue;

                       }
                                  
     3. Class Selector : Applying the style on a group of html elements

      Syntax :  .ClassName {

                                    CssPropertyName : PropertyValue;

                       }


     4. Grouping selector / Group elements selector : 
 
         if you want to apply the style on group of elements 

         Syntax : 
                  element1 , element2, element3 , element4{
                        Cssproperityname : propertyValue;
                  }
    --->Note : To comment out the lines in css the syntax is 
       /*    */

     6. Child Selector - (>)

--> Cascade :  Cascade is a mechanism  it tell which selector should wins , later selector only wins
    when multiple selctors affects the same element
   
    Rules :  
    1.check the position
    2.see the Selectors

    ex : 
         p{
            color:blue;
         }
        
         .p{
            color:purple;
         }

--> Attribute selector : 
              
              input[attribute ="attribute value"]{
                propertyName :  PropertyValue;
              }

    -->Specificity : 

        Specificity is the weight that browsers use in the cascade algorithm to determine 
        the CSS declaration that is the most relevant to an element, 
        Not always the later wins every selector as some strength 

     1.element selector (p) -- very Low (0,0,0) -- 0
     2.attribute selector(input[attribute="attribute value"]) -- low(0,0,1) -- 10
     3..Class selector(.p)--Low --(0,1,0)-10
     4.#id selector(#p)--High(1,0,0)-100
     5.inline css(style="Property")--VeryHigh(1,1,1)-1000
